# Structura
1. Crée un dépôt GitHub et envoie tous ces fichiers (branche main).
2. Onglet Actions > Build APK (se lance seul). Attends environ 5 à 8 minutes.
3. Ouvre l’exécution terminée, section Artifacts, télécharge Structura-APK, installe l’APK.
La clé API Gmail se saisit dans l’appli (Menu > Réglages), jamais dans le code.
